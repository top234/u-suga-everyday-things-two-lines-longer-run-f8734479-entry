Entry for the [make.fun bounty "Everyday Things, Two Lines, Longer Run"](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479).

`main.ts` (Node 22+, standard library only, no network) writes one two-line
text to `/output/entry.txt`: it explains a traffic jam to a 10-year-old
through one concrete analogy — a parking lot that forgot it was a road —
and then says honestly what that analogy maps and what it leaves out.

## Run it

```sh
node main.ts
```
